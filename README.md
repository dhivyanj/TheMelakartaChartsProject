An open-source reference library providing structured data (**CSV**) and visual reference charts (**PDF**) for the 72 **Melakarta Ragas** of Carnatic Music.

---

## 📌 Project Overview

This repository serves as a digital library for musicians, musicologists, students, and software developers. It provides accurate tabular data detailing **Chakra**, **Swaras**, **Katapayadi numbers**, and **Names**, along with high-quality visual charts for quick study and printing.

### Highlights
- **CSV Tables:** Clean, structured data ready for programmatic analysis.
- **PDF Reference Charts:** High-resolution radial maps suited for printing and offline reference.
- **Multilingual Vision:** Expanding to support all common and archaic scripts.

## 📖 Data Schema (`kn.csv`)

The tabular dataset contains the following attributes for each of the 72 ragas:

| Column | Description | Example |
| :--- | :--- | :--- |
| `raga_number` | Katapayadi index (1–72) | `29` |
| `raga_name` | Name of the Melakarta Raga | `ಧೀರಶಂಕರಾಭರಣಂ` |
| `chakra_number` | Chakra group index (1–12) | `5` |
| `chakra_name` | Name of the Chakra | `ಬಾಣ` |
| `swaras` | Swara combination formula | `ಸ ರಿ₂ ಗ₃ ಮ₁ ಪ ಧ₂ ನಿ₃ ಸ` |
